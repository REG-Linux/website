# 🧩 REG Linux Wiki

Welcome to the **REG Linux Wiki** — the official documentation site for **REG Linux**,  
an **immutable Linux system for retro gaming devices**.

🌐 **Live site:** [https://reglinux.org/wiki/](https://reglinux.org/wiki/)  
📦 **Repository:** [REG-Linux/website](https://github.com/REG-Linux/website), folder `wiki/`

---

## 📖 About

REG Linux is a lightweight, immutable Buildroot-based operating system designed for:
- Retro gaming handhelds and mini-consoles  
- ARM, AArch64, RISC-V, and x86_64 platforms  
- Developers and tinkerers who value performance, reproducibility, and simplicity  

This wiki documents everything from installation to internal architecture, build guides, and community resources.
